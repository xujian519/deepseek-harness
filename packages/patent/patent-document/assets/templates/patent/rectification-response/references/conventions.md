# 补正书 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md` 配套。

## 1. 文书结构（固定顺序）

1. 页眉（所名 + 密级；正式提交版可删除）
2. 文书抬头（类型徽标 / 标题 / 案卷号）
3. 案件信息表（申请号 / 发明名称 / 申请人 / 通知书文号 / 补正期限 / 答复日期）
4. 补正通知要点
5. 补正内容对照表
6. 替换页清单
7. 未超范围声明
8. 落款 + 免责声明 + 页脚（正式提交版可删除）

## 2. 补正内容表规范

- 逐缺陷项一行，序号与通知缺陷一一对应；主动补正项在「性质」列标注「主动补正」。
- 「补正前」「补正后」引用原文位置（如「权利要求书第 1 页第 3-5 行」），不允许只写结论。
- 性质列取值：通知书缺陷 / 主动补正。

## 3. 替换页清单规范

- 页号必须与实际提交文件一致；版本号从 V1 开始递增。
- 替换内容摘要引用补正内容表序号，形成交叉定位。

## 4. 期限与程序

- 补正期限 = 通知书落款日 + 指定期限，用工具计算，禁止心算。
- 超过期限的答复必须同时说明恢复权利请求，不能只提交补正书。

## 5. 内部审稿版 vs 正式提交版

| 元素 | 内部审稿版 | 正式提交版 |
|---|---|---|
| 页眉密级 | 保留 | 删除 |
| 免责声明 | 保留 | 删除 |
| 落款签名 | 保留 | 删除 |
| 页脚 | 保留 | 删除 |

## 6. 视觉与版式纪律

- 沿用 `assets/templates/patent/tokens.css` 品牌变量；agent 不改样式。
- 表格行避免跨页断裂（`page-break-inside: avoid` 已内置）。
- 申请号、文号等使用等宽字体（`.mono`）。

## 7. 品牌契约注入点

同 `assets/templates/patent/DOCS.md` 与 `tokens.css`。抬头所名、密级由 CSS 变量注入。
