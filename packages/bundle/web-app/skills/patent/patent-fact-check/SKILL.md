# 事实核验

对交付物中每一句事实性断言做可溯源核验。任一断言拿不出可验证来源即整体不通过，打回补证。

## 四类核验

1. 法条：引用条文（A22.2/A22.3/A26.3/A26.4/A33/A9 等）对照 `~/.agents/skills/patent-legal/_shared/patent-law-baseline-2024.md`；基线未覆盖或存疑时检索原文（patent_case_search / patent_wiki_search / web）。核验失败 → 删除或改写断言，不保留"好像有"。
2. 判例：案号、决定号、裁判要点逐项核对来源（patent_case_search 命中记录或知识图谱节点），标注出处。核验失败 → 不引用。
3. 对比文件：编号（D1/D2…）、公开号、段落 pin-cite、公开日早于申请日/优先权日。文件未打开验证 → 不用于结论。
4. 日期数字：申请日/优先权日/期限/费用用 tool-bash 计算，命中数与页码以工具返回为准，禁止心算。与来源不符 → 回退重算。

## Fail-Closed

- 任何一类存在未溯源断言 → 门禁不过，交付物打回。
- 全部通过才允许进入 patent-compliance-review 与交付。
- 本闸门不替代人工复核：交付说明中明示。

## 流程

逐句扫描交付物 → 标注每条事实断言的来源 → 按四类核验 → 记录不通过项 → 补证或删除 → 重核 → 全过放行。
