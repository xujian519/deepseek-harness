# 无效宣告分析

分析目标专利的无效理由，评估证据组合与成功率。

## 必查清单（先查再分析）

- 用 patent_case_search 查相似无效决定的证据认定：多文件结合技术启示、单文件+公知常识、现有技术认定、不清楚认定、充分公开认定、修改超范围与优先权。
- 用 patent_kg_query 追查复审无效推理模式裁判规则。
- 用 cnlaw MCP 的 `mcp__cnlaw__*` 或 patent_case_search 核验所引条款的法条原文（A22.2 / A22.3 / A22.4 / A2 / A5 / A25 / A26.3 / A26.4 / A33 / A9、细则第 23 条第 2 款、细则第 49 条），需要打开页面时用 `web_fetch`。

## 无效理由地图

法条与理由的对应以确定性理由表为准（`packages/patent/patent-core/src/notice/grounds.ts`）；下表按该表的口径列出，识别结果里的 `matched` 是命中处的原文片段，用于人工核对命中是否被实质论证。

| 理由 | 法条依据 | 说明 |
|---|---|---|
| 新颖性 | 专利法第 22 条第 2 款 | 证据公开日须早于申请日/优先权日；单篇对比文件公开全部技术特征 |
| 创造性 | 专利法第 22 条第 3 款 | 三步法：最接近现有技术 → 区别特征与实际解决的技术问题 → 结合启示 |
| 实用性 | 专利法第 22 条第 4 款 | 不能制造或使用、无积极效果 |
| 客体 | 专利法第 2 条 / 第 5 条 / 第 25 条 | 不属于技术方案、违反法律或社会公德、属于不授予专利权的范围 |
| 充分公开 | 专利法第 26 条第 3 款 | 不依赖外部证据，聚焦文本 |
| 清楚/支持 | 专利法第 26 条第 4 款 | 权利要求不清楚、得不到说明书支持 |
| 必要技术特征 | 专利法实施细则第 23 条第 2 款 | 独立权利要求缺少解决技术问题的必要技术特征 |
| 修改超范围 | 专利法第 33 条、实施细则第 49 条 | 超出原说明书与权利要求书记载的范围；分案申请同理 |
| 重复授权 | 专利法第 9 条 | 同样的发明创造 |

单一性（专利法第 31 条第 1 款）**不是**无效理由，不得作为无效请求的理由提出。

## 分析流程

1. 拆解独立权利要求，识别核心创新点与弱点（必要特征/上位概念/功能性限定/不清楚之处）。
2. 理由识别走确定性内核：用 patent_workflow_run（manifestId=patent_invalidation_v1；input=无效宣告请求书或对方理由，claims=权利要求书）跑一遍，grounds 阶段按无效理由表识别文书援引的理由，claim-chart 阶段（mode=invalidity）做要素级证据映射，novelty 与 inventiveness 收口阶段同时读到理由与对照表。识别结果只表示正文提到了该条款，是否被实质论证须按 `matched` 原文片段人工核对；无命中时不得替文书认定理由。
3. 检索申请日前公开的证据并评估相关度；对比文件公开日须早于涉案专利的优先权日/申请日（有优先权的以优先权日为准），中间文件、抵触申请单独标注。
4. 每条权利要求构建至少 2 条无效路径作为**内部预案**（主路径 + 备选路径），记录各自的成功率与风险点。预案用于评估与应对，**不等于对外文书的主张**：请求书只写经筛选后站得住的主张，同一权利要求的多条内部路径合并为对外的一条主张，从属权利要求与其引用的权利要求使用同一法条路径（引用的权项以 A22.3 主张时，从属权项亦以 A22.3 承接）；claim_chart_build 的 invalidity_conclusion 报出的"仅附加特征被覆盖"形态必须先处理，不得绕开。
5. 证据组合策略至少 3 种（D1 单独 / D1+D2 / D1+公知常识 / 证据链），并用 claim_chart_build（mode=invalidity）逐要素钉住每篇证据的公开内容与段落位置；它随图表给出的 invalidity_conclusion（逐权项单篇全覆盖、区别特征、从属权项法条路径、引用关系缺陷）是程序按行级映射算出的，不得与之相反。对外文书的证据清单只列实际使用与必要的备用证据，不逐一罗列全部检索所得。
6. 基于复审无效决定评估成功率，每个理由给出成功与失败风险点。

## 输出

无效策略报告：证据清单 + 无效理由 + 成功率 + 风险评估。

正式出件用官方标准表格：请求书用 101001 专利权无效宣告请求书，补充意见与答复转送文件通知书用 100902 复审、无效宣告程序意见陈述书，正文均转入 100014 附页；附件栏（101001 ⑨栏、100902 ⑦栏）逐条写明名称、份数、页数、原件或复印件——份数与页数不在本流程登记，出件时按附件实物补填（模板库 `~/.dsh/patent-ops/templates/cnipa-标准表格/`）；口径见模板 `invalidation-opinion` 的 `references/conventions.md` §7。代表专利权人（被请求人）答辩是另一项作业：流程、期限与依据见 patent-invalidation-defense 技能，出件用 `invalidation-defense` 模板，载体同为 100902 意见陈述书。

## 质量门禁与人工确认

证据公开日逐一核验；无效理由组合先 ask_user_question 确认再起草；报告附免责声明；交付前经 patent-quality-gate。
