# 审查意见答复省略空的可选节

[English](guide.md) | 中文

## 变更

`render_patent_document` 在 `template: 'oa-response'` 下，把草案没有给出内容的可选节整块移除，而不是渲染一个标题套着空容器：

- `argument-other`——「5.3 其他争点」的标题与槽位一起移除。
- `formalities-body`——「六、其他缺陷的处理」整节，含标题。

删节会在中文章节序号里留下缺号，因此渲染器按文档顺序把其余章节级标题重编为 1..N，并改写其下小节标题的 `<节号>.<序>` 前缀：草案不含 `formalities-body` 时，「七、证据与引用」渲染为「六、证据与引用」，`7.1`／`7.2` 渲染为 `6.1`／`6.2`。重编号只在确实折叠过小节时执行，其余模板的编号一个字符都不动。

每个被折叠的节都写进渲染结果的 `warnings`：`已折叠空节：<标题>（槽位 <id> 无内容）`。

模板正文同时去掉了原先挂在三、本案事实，四、适用规则，五、意见陈述，六、其他缺陷的处理与 7.2 之下的起草指令。这些纪律写在 `references/conventions.md` 里、面向起草人；交付物现在只有给读者看的正文。

拿渲染结果与存档样张逐字对比的人，以及从成品里读取固定节号的人，都受影响。

## 迁移

1. 不要假定答复稿有八节：读 `已折叠空节` 告警或渲染出的 HTML，判断「六、其他缺陷的处理」是否存在。
2. 从文档里读节号，不要写死；折叠之后证据节是「六、」而不是「七、」。
3. 用小节标题文本（`证据清单`）定位，不要用 `7.1` 这类前缀。
4. 要求每份交付物都出现某一节时，给它的槽位写一句话（如 `本次审查意见未涉及其他争点`）：折叠只对缺席或空槽位生效。
5. 重录含渲染结果的样张——折叠与重编号都会改动 HTML——并运行 `pnpm exec vitest run packages/patent/patent-document/tests`，确认模板结构、草案骨架与折叠用例。
