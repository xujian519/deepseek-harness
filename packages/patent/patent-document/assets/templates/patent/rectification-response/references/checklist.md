# 补正书 — 自查清单（Checklist）

> 输出定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 案件信息表填满（申请号、发明名称、申请人、通知书文号、补正期限、答复日期）
- [ ] 补正期限数值由工具计算并写入，无手算痕迹
- [ ] 补正内容表逐缺陷项一行，序号与通知书缺陷一一对应
- [ ] 每个「补正前」「补正后」均引用原文位置
- [ ] 替换页清单页号与提交文件一致，版本号连续
- [ ] 未超范围声明在场，依据专利法第三十三条
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 主动补正项已标注「主动补正」
- [ ] 通知中未涉及的章节明确说明未作改动
- [ ] 超出期限的答复附恢复权利说明

## P2 — 锦上添花

- [ ] 提供 `.md` 源稿便于后续修订
- [ ] 导出 PDF 后抽查表格是否跨页断裂
