# 实用新型/外观设计专利权评价报告 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md`、`citation-log.md` 配套。

## 1. 分区顺序（固定）

1. 著录项（专利号 / 申请日 / 优先权日 / 授权公告日 / 名称 / 专利权人 / 请求人 / 请求日 / 总计页数与副本份数）
2. 评价所针对的文本
3. 检索针对的权利要求
4. A. 主题的分类（IPC）
5. B. 检索领域
6. C. 在检索时查阅的电子数据库
7. D. 相关文件（类型 / 文献号 / 公开日 / 分类号 / 相关部分 / 相关权利要求编号）
8. 图例（`*` 引用文件的专用类型）
9. E. 关于是否符合授予专利权条件的评价结论；专利权评价意见
10. 落款（专用章 / 审查员 / 审核员 / 完成日期）

## 2. 值位与表格

- 值位一律用 `.fill`；横线长度随填写内容伸缩，空位保留最小长度。
- 表格行数按内容条数复制数据行：D 表行数 = 相关文件条数，超出本页时勾选「相关文件，参见续页 I」。
- 列宽随内容伸缩（`table-layout: auto`），不写死列宽。
- 第 3 页之后的续页张数由评价意见长度决定：复制续页 II 整块与页眉，内容不足一页时删除该页。

## 3. 版式来源与视觉纪律

- 本模板复刻国家知识产权局《表格 220701（2011.4 版）》版式，**刻意使用黑白表格线、不套用 `tokens.css` 品牌色**，以贴近官方原件外观；这是刻意选择，不是遗漏。
- 版式参数：正文 10.5pt、行距 1.5、版心 177mm。
- 抬头区留空；用作模拟件时在抬头区显著标注「模拟件 · 非行政机关出具」。

## 4. 相关文件表（D）

- 类型取 X / Y / A / E / R，含义见图例。
- 每条相关文件写全：类型、文献号、公开/出版/发行日期、分类号、相关部分、相关的权利要求编号。
- 相关部分指向说明书段号或附图编号，不写「全文」以外的模糊表述。

## 5. 结论与意见

- 初步结论与「具体结论如下」逐条对应，勾选状态须与评价意见一致。
- 评价意见逐条（1、2、3…）组织，每条写「事实认定 → 对比 → 结论 → 法条」。
- 法条引用精确到条款号。

## 6. 引用与溯源

同 `citation-log.md`；D 表即引证来源，正文每处对比引用对应 D 表一行。
