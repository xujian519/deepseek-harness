# 指南索引新增 2026 节覆盖

[English](guide.md) | 中文

## 变更

`LawBaseline` 新增 `versions`，用于登记后续修订版的节级覆盖。随包指南索引现有 `2026 年修订版（2026-01-01 施行）` 一项，收录 2025-11-13 修改对照表（局令第84号）确认修改的 3 节：第二部分第一章4.4、第四部分第三章2.1、第四部分第三章3.3。正文按官方对照表新栏转录，并按颜色标记剔除了删除文字。其余 61 条节级条目仍是 2023 年文本，不声称已按 2026 年版更新。

`verifyCitation` 新增 `VerifyOptions.revision`。未指定时使用最新已转录的覆盖；覆盖不到的节仍用基础文本。指定基础版本（`2023 年修订版（2024-01-20 施行）`）时，这 3 节按 2023 年文本判定，并经 `staleSections` 报 `unverified`。指定索引没有的版本时报 `unverified`，不回退。

`law_verify` 工具没有版本参数，因此默认使用最新覆盖：引用这 3 节时，现在会按 2026 年文本报 `valid`（或按命题作出判定），不再报 `unverified`。

## 迁移

1. 如果直接构造 `LawBaseline`，在没有后续修订版时补 `versions: []`。随包加载器会从资产填充该字段；只有手写测试夹具和工具需要补。

2. 如果测试原本期望这 3 节报 `unverified`，可改为接受 2026 年判定，或传 `{ revision: '2023 年修订版（2024-01-20 施行）' }` 保留旧行为。

3. 不要把索引当成完整的 2026 年版：只有这 3 节带 2026 年文本，其余节仍是 2023 年修订版，索引路径也尚未按 2026 年版改号。

4. 用 `pnpm exec vitest run packages/patent/patent-law/tests` 确认。
