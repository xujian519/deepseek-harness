# 实用新型/外观设计专利权评价报告 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 文书性质正确：用作转制时保留原报告著录项；用作模拟件时抬头区显著标注「模拟件 · 非行政机关出具」，不使第三方误认为行政机关出具
- [ ] 分区顺序与 `conventions.md §1` 一致
- [ ] 著录项填满（专利号、申请日、授权公告日、名称、专利权人、请求人、请求日）
- [ ] 「评价所针对的文本」与「检索针对的权利要求」勾选状态正确
- [ ] A–E 分区完整；D 表每条相关文件六列填全
- [ ] D 表行数与著录项「副本份数」一致
- [ ] 初步结论与「具体结论如下」逐条对应，且与评价意见不矛盾
- [ ] 法条引用精确到条款号
- [ ] 对外件不含内部工作章节（待办／待核／核验记录／修订记录等）
- [ ] 示例与产出件不得含真实案卷信息（专利号、名称、当事人、审查员与审核员姓名、日期、对比文件号均为虚构或已脱敏）
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 相关文件按相关度降序排列，类型标注为 X / Y / A / E / R
- [ ] 续页 II 张数与评价意见长度匹配，不足一页时删除
- [ ] 表格数字列使用 tabular 数字

## P2 — 锦上添花

- [ ] 导出 PDF 后抽查跨页表格是否断裂
