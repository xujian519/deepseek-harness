# 专利快速开始

[English](patent-quickstart.md) | 中文

本指南从一份源码检出开始，完成第一条专利任务。起点是 [Web UI 已启动](../../../README.zh.md#run)。

## 开始之前

- 从源码构建需要 Node.js >= 24.9 与 pnpm 11.28.5。
- 一个 DeepSeek API key。
- 本机上的案卷目录，包含交底书与参考资料。

## 启动 Web UI

在仓库根目录运行：

```sh
pnpm install
pnpm run build
pnpm dsh web
```

本分支的能力不包含在上游发行包中，因此必须使用这次源码构建。

## 配置模型与工作区

1. 打开**设置 → 模型**，填入 DeepSeek API key 并保存。
2. 选择案卷目录作为工作区。

## 选择专利预设

新建任务并打开 Agent 预设选择器，选择发布名为**专利模式**的专利组合。任务开始后预设即固定，因此在发送第一条消息前完成选择。

## 运行第一条任务

发送一个范围明确的需求：

> 读取本工作区的交底书，列出技术问题、发明构思、关键技术特征与技术效果。

Agent 在动手前会复述任务范围与每个关键取舍并等待确认；引用法条前会先核验。

## 预期行为

- 输出为起草辅助，不构成正式法律意见。
- 检索报告写明数据来源、检索式、检索日期与覆盖范围。
- 每条事实性断言都带来源；拿不出来源的断言会被撤回。
