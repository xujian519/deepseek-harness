# 复审请求书 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md` 配套。

## 1. 文书结构（固定顺序）

1. 页眉（所名 + 密级；正式提交版可删除）
2. 文书抬头（类型徽标 / 标题 / 案卷号）
3. 案件信息表（申请号 / 发明名称 / 请求人 / 驳回决定文号与日期 / 复审期限 / 提出日期）
4. 请求复审的理由（驳回要点摘录 → 逐条回应）
5. 修改方案（修改对照表 + 修改依据）
6. 法律依据与程序说明
7. 请求事项
8. 落款 + 免责声明 + 页脚（正式提交版可删除）

## 2. 复审理由规范

- 逐条针对驳回决定所列理由回应，不得遗漏或另起无关联新论点。
- 每条回应含：对事实认定的意见、对法律适用的意见、支持的证据（对比文件公开号/页码）。
- 引用驳回决定原文时给出条款或段落序号。

## 3. 修改方案规范

- 修改对照表中「修改依据」指向原说明书/权利要求书的具体位置（页码）。
- 修改仅允许删除、合并、缩小范围等法定方式；新增特征或扩大范围不作提交。
- 修改后的权利要求书全文作为附件，与对照表一致。

## 4. 期限与程序

- 复审期限 = 驳回决定送达日 + 3 个月（以工具计算，禁止心算）；超过时写明恢复请求窗口。
- 请求事项中的「给予听证机会」仅适用于有争议需要口审的情形。

## 5. 内部审稿版 vs 正式提交版

| 元素 | 内部审稿版 | 正式提交版 |
|---|---|---|
| 页眉密级 | 保留 | 删除 |
| 免责声明 | 保留 | 删除 |
| 落款签名 | 保留 | 删除 |

## 6. 视觉与版式纪律

- 沿用 `assets/templates/patent/tokens.css` 品牌变量；agent 不改样式。
- 表格行避免跨页断裂（`page-break-inside: avoid` 已内置）。
- 申请号、文号、日期使用等宽字体（`.mono`）。

## 7. 品牌契约注入点

同 `assets/templates/patent/DOCS.md` 与 `tokens.css`。抬头所名、密级由 CSS 变量注入。
