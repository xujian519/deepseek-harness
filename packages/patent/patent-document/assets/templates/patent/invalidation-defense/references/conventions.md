# 无效宣告程序意见陈述书 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md` 配套。本模板产出**被请求人（专利权人）侧的对外提交件**：答复请求人的无效宣告请求。请求人侧的请求书用 `invalidation-opinion`，内部评估用 `invalidation-analysis`。

## 1. 文书结构（固定顺序）

1. 页眉（所名 + 密级）
2. 文书抬头（类型徽标 / 标题 / 案件编号）
3. 案件信息表（涉案专利号 / 专利名称 / 授权公告日 / 专利权人 / 无效宣告请求人 / 无效宣告请求日 / 转送文件通知书 / 指定答复期限届满日 / 陈述意见日期）
4. 一、答辩意见概述
5. 二、程序性意见
6. 三、关于请求人提交证据的意见
7. 四、权利要求书的修改
8. 五、逐项答辩
9. 六、证据清单
10. 七、逐权利要求结论
11. 八、结论与请求
12. 落款 + 免责声明 + 页脚

八个章节缺一不可：不适用时也要写明不适用的结论（见 §2 末、§3 末、§6 末），不得整节删除后留下空标题。

## 2. 程序性意见的依据（第二章节）

程序性意见与实体答辩分开成节：程序上的异议一旦成立，实体答辩即无须展开，混写会让读者无法判断哪一项主张是独立的。

- **陈述意见的义务与期限**：专利法实施细则第 72 条（国务院专利行政部门应当将请求书和有关文件的副本送交专利权人，要求其在指定的期限内陈述意见；专利权人和请求人应当在指定期限内答复转送文件通知书或者无效宣告请求审查通知书，期满未答复的不影响审理）。指定答复期限一般为一个月（审查指南第四部分第三章4.4.1）。
- **指定期限不得延长**：专利法实施细则第 75 条（无效宣告请求审查程序中指定的期限不得延长）。答复期限本身不能申请延长；这与延期举证不是一回事——审查指南第四部分第三章4.3.3 的延期举证，是当事人因无法克服的困难而在期限内书面请求延期**提交某项证据**，不能用来延长答复期限。
- **审查范围**：合议组通常仅针对当事人提出的无效宣告请求的范围、理由和提交的证据进行审查（审查指南第四部分第三章4.1）。请求人在提出请求时没有具体说明的理由以及没有用于具体说明相关理由的证据，且在提出之日起一个月内也未补充具体说明的，不予考虑。
- **专利权人的举证期限**：审查指南第四部分第三章4.3.2。专利权人应当在指定的答复期限内提交证据；技术词典、技术手册和教科书等公知常识性证据，以及用于完善证据法定形式的公证文书、原件等证据，可以在口头审理辩论终结前补充。提交或者补充证据的，还应当在上述期限内对该证据具体说明；外文证据的中文译文期限适用该举证期限。不符合期限或者未具体说明的，合议组不予考虑。
- **一事不再理**：专利法实施细则第 70 条第 2 款；审查指南第四部分第三章2.1。
- **听证原则**：审查指南第四部分第一章2.5。合议组在作出对其不利的决定前，应当给予该当事人针对决定所依据的理由、证据和认定的事实陈述意见的机会；据此，合议组依职权引入的理由或者证据，专利权人有权在指定期限内陈述意见。

无程序性异议时，本节写明确的否定结论：请求人的主体资格与请求书形式符合规定，专利权人不提出程序异议。**本节不写己方的程序风险或应对预案**（属内部记录，见 §9）。

## 3. 权利要求书的修改（第四章节）

- **依据**：专利法实施细则第 73 条（发明或者实用新型专利的专利权人可以修改其权利要求书，但是不得扩大原专利的保护范围；不得修改专利说明书和附图；外观设计专利的专利权人不得修改图片、照片和简要说明）；审查指南第四部分第三章4.6.1（修改原则）、审查指南第四部分第三章4.6.2（修改方式）、审查指南第四部分第三章4.6.3（修改方式的限制）。
- **修改原则四项**（审查指南第四部分第三章4.6.1）：不得改变原权利要求的主题名称；与授权的权利要求相比不得扩大原专利的保护范围；不得超出原说明书和权利要求书记载的范围；一般不得增加未包含在授权的权利要求书中的技术特征。外观设计专利的专利权人不得修改其专利文件。
- **修改方式**（审查指南第四部分第三章4.6.2）一般限于：权利要求的删除、技术方案的删除、权利要求的进一步限定、明显错误的修正。「进一步限定」是指在权利要求中补入其他权利要求中记载的一个或者多个技术特征，以缩小保护范围。
- **时机限制**（审查指南第四部分第三章4.6.3）：审查决定作出之前，专利权人可以删除权利要求或者权利要求中包括的技术方案；**仅在**下列三种情形的答复期限内，才可以以删除以外的方式修改权利要求书——针对无效宣告请求书；针对请求人增加的无效宣告理由或者补充的证据；针对合议组引入的请求人未提及的无效宣告理由或者证据。不在上述情形之一时，本节只能作删除式修改，其余修改主张不得写入本件。
- **未修改时的写法**：说明段写「本次答复未修改权利要求书」，表 1 只登记一行，修改方式列写「未修改」，其余列写「—」。不得为了让表格显得充实而编造修改。
- **修改后的权利要求全文**随附页或者替换页提交，不逐条抄进本节；表 1 只登记修改前、修改后的要点与出处（原说明书段号或者其他权利要求号）。

## 4. 逐项答辩的组织（第五章节）

- **一节对应请求书实际主张的一项理由**。请求书未主张的理由不得出现在本件；已被主张的每一项理由都必须有一节回答。
- 节标题由渲染器按草案结构生成，形如 `5.1 权利要求 1、3 的创造性（专利法第 22 条第 3 款）`：节序（`5`）与权项和理由名之间的关系词（「的」）取自模板体例，被主张的权项号、理由名与法条取自草案。**起草时不得手写小节标题**——手写会让只回答部分理由的答复件凭空多出一节，或者漏掉请求人已主张的理由。理由名写成名词短语（「创造性」「新颖性」「说明书支持与清楚」），小节按主题命名，答辩结论写在正文里。
- 每节按请求人侧同一「四段式」给出：**事实认定** → **证据分析** → **法条适用** → **结论**；后两段由渲染器合并为一个「法条适用与结论」小标题与一段正文，因此只提交三段正文（四段式的完整说明见 `invalidation-opinion/references/conventions.md` §3）。被请求人侧与请求人侧共用同一节骨架，只是断言方向相反，因此「事实认定」段同时写明请求人在该理由下主张的事实与证据（注明其出处），「证据分析」段给出专利权人对该证据的意见。
- 「证据分析」段按可核查的顺序展开：对方证据的公开内容与其缺陷（引 pin-cite）→ 本专利相应技术特征在说明书中的记载 → 为何不构成公开或者不存在技术启示。**不得只作结论式陈述**：写「未公开」「无技术启示」必须同时指出对方证据的哪一处、以何理由不支持其主张。
- 「法条适用与结论」段必须回应请求人在该理由下主张的**每一条**权利要求。从属权利要求与其引用的权利要求同一路径：被主张的从属权利要求包含引用权利要求的全部技术特征，在引用权利要求具备新颖性、创造性的基础上同样具备新颖性、创造性；不得以「附加技术特征未被公开」以外的自相矛盾写法作答。
- 理由的成立与否以 `claim_chart_build`（mode=invalidity）随图表算出的 `invalidity_conclusion` 为机械核验：它逐权项判定单篇全覆盖与区别特征。本件的主张不得与该核验相反；核验报出「仅附加特征被覆盖」时，须按该形态组织答辩，不得回避。

## 5. 对请求人证据的质证意见（第三章节）

- 逐份证据按**真实性、合法性、关联性**三项陈述，一项有异议即单独写出异议及其依据；无异议的也写明「无异议」，不得省略。
- 三性的具体落点：
  - **复印件**：请求人未提交原件核对时，对其真实性不予认可。
  - **外文证据**：未在举证期限内提交中文译文的，主张该证据不予考虑（审查指南第四部分第三章4.3.2；外文证据的提交见审查指南第四部分第八章2.2.1）。
  - **域外证据**：未按规定的证明手续办理的，主张其不具备形式要件。
  - **互联网证据**：页面未记载发布时间、且无其他凭证印证公开时间的，主张公开时间不能确定，不得作为现有技术使用（审查指南第四部分第八章5.1）。
  - **公知常识**：请求人以「本领域常规技术手段」主张而未提交证据的，指出公知常识的认定应当有证据支撑（审查指南第四部分第八章4.3.3）。
- 质证意见只就证据本身陈述，不在本节展开实体结论；实体结论写入第五章节并在那里引用同一证据编号。

## 6. 证据清单的登记口径（第六章节）

本节的证据清单只登记**专利权人提交的证据（反证）**。请求人提交的证据沿用请求书的编号，在本件不重新登记——重新登记会让两套编号在同一程序里混淆。

- 反证的编号列写 `反证` 加序号（`反证1`、`反证2`…），编号列不留空。
- 表头、标识列写法、日期列写法、用途列写法与登记口径与请求人侧同一口径源：`invalidation-opinion/references/conventions.md` §4.1。本节不重述该口径，两份清单与内部件共用它。
- 正文引用的反证编号必须已登记，登记的反证编号必须在正文引用一次；编号形态取自编号列本身，因此正文提到请求人的「证据 1」不会被当成未登记的反证。
- 未提交任何证据时，表内登记一行，编号列写「—」，名称列写「本次答复未提交证据」，其余列写「—」；正文不引用该行。

## 7. 逐权利要求结论表（第七章节）

- 「答辩结论」列写专利权人的请求结果（请求维持有效 / 同意宣告无效 / 请求在修改后的权利要求基础上维持有效）。
- 「对应理由」列写法条缩写（`A22.3`、`A26.4` 等），与第五章节的小节号相互对应（如「见 5.1、5.2」）。
- 覆盖请求人主张的**全部**权利要求，不只覆盖独立权利要求。
- 本件不写己方胜率与结论分档——那是内部评估，写在 `invalidation-analysis` 件或案卷内部文件里。

## 8. 视觉与版式纪律

- 沿用 `assets/templates/patent/tokens.css` 品牌变量；agent 不改样式。
- 表格数字列使用 `tabular-nums`。

## 9. 对外提交件与内部记录的分离

本模板产出对外提交件，与 `invalidation-opinion` 同一分离口径：禁止项、渲染器的三类机械检查（章节编号、标题与正文用语表、证据编号两侧对齐）与仍为人工检查的项，见 `invalidation-opinion/references/conventions.md` §6.1。本件另有两条同源要求：请求人证据的质证意见只写实际提出的异议，己方评估与应对预案不入本件；答辩要点不写「预期结果」「风险评估」一类己方预判。

## 10. 正式提交件的载体（所外）

本模板产出的 HTML/PDF 是**所内复核稿**。向国家知识产权局提交时：

- 载体系 `100902 复审、无效宣告程序意见陈述书`：⑤栏勾选「针对国家知识产权局于 ×××× 年 × 月 × 日发出的……通知书（发文序号……）陈述意见」，陈述意见写 ⑥栏，附件列 ⑦栏；⑥栏填写不下的使用 A4 纸作为附页续写（`100014 附页`）。
- 本件（所内复核稿）的证据清单只登记标识、名称与日期；⑦栏要求的另三项——份数、页数、原件或复印件——在按 ⑦栏出件时逐条填写：份数按「一式两份」规定，页数按附件实物，原件或复印件按实际提交形态。出件的 ⑦栏清单与本件证据清单逐条对应：本件修一条，⑦栏改一条。
- 当事人提交的意见陈述书及其附件应当一式两份（审查指南第四部分第三章4.4.1）。
- 栏位顺序与其余载体口径见 `invalidation-opinion/references/conventions.md` §7；版式源＝本地模板库 `~/.dsh/patent-ops/templates/cnipa-标准表格/`（仓外维护）。更新任一者时须核对另一者。
