# 专利诉讼文书 — 自查清单（Checklist）

> 输出定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 文书类型（起诉状/答辩状）与标题、徽标一致
- [ ] 案件信息表填满（案由、受理法院、案号、涉案专利号、提交日期）
- [ ] 当事人信息表双方齐备，名称与公开登记一致
- [ ] 起诉状诉讼请求逐项列明（停止侵害、赔偿、合理开支、诉讼费）
- [ ] 赔偿金额有计算依据，非无来源数字
- [ ] 答辩状逐项回应起诉状主张（事实/证据/法律适用）
- [ ] 证据清单编号连续，证明内容与事实一一对应
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 答辩期 = 收到副本 + 15 日，由工具计算
- [ ] 合理开支单列并附依据
- [ ] 管辖依据写明（侵权行为地/被告住所地）

## P2 — 锦上添花

- [ ] 提供 `.md` 源稿便于后续修订
- [ ] 导出 PDF 后抽查证据表是否跨页断裂
