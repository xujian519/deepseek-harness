# Agent Note: A pre-registered measurement protocol for LLM-scored before/after comparisons

Status: implemented

[English](2026-10-16-patent-eval-measurement-protocol.md) | 中文

## Problem

patent-oas 用 LLM 评分的运行把一次优化与基线作对比,而 2026-10-12 的论文评审(论文 08 §6.6、论文 10)记录了没有协议时的后果:同一任务族上同一干预在 N=10 时得 +0.84、N=300 时得 −0.12——符号反转,小样本对比测不出,仓库里也没有任何门禁能拦住。运行器缺省每 case 只跑一次,记录不带用量数字,也没有任何东西要求一次对比在花掉调用之前先说清样本量、阈值与预算。

## Decision

**每一次用 LLM 评分的前后对比,都在第一次调用之前预注册四件事**:每个 case 的运行次数(至少 3——运行器缺省值)、统计量与判定阈值(门禁的 case/node 底线与允许回退)、该设计必须能检出的预期效应量、以及这次对比可花掉的预算。没有预注册的对比是冒烟运行,不是证据,也不得当作证据上报。

**case 内 Δ 是报告单位。** 论文 08 的测量只在 case 内成立:绝对相似度与绝对分数不可跨 case 比较,因此对比报告「逐 case Δ」与门禁推导出的逐节点 Δ,绝不单独报告一个绝对值。跨 case 均值仍作回归信号保留,但从不单独出现。

**随机检索探针不进交付链路。** 论文的无标注探针技术用于离线区分「有依据的修改」与「先验注入」;接进工作流会让答复引用未实际覆盖检索的材料,违反「检索未覆盖不得下新颖性结论」。检索探针是离线评测工具(随 B4 批次落地),永远不是流程阶段。

**每一次记录的对比都携带用量。** run 记录可携带 `cost` 与 `tokens`;采集器把运行器调用接缝报告的用量求和。记录在案的对比要么填上它们,要么写明为何不能——没有成本的对比无法排期与预算。

## Alternatives considered

**只信 case 均值。** 被同一份评审否决:它随 rubric 构成漂移且无法归因,这正是问题空间 DAG 门禁([2026-09-26](2026-09-26-patent-oas-problem-space-gate.zh.md))按节点判定的原因。

**看过第一批之后再定样本量。** 否决:先偷看再定 N 正是符号反转的成因;预注册的意义就是数字在花调用之前定死。

**现在就把完整统计(方差、功效曲线)做进运行器。** 暂不采纳:最小升级——runs 大于 1 加用量字段——是当前运行器与门禁能强制的东西;更重的统计留给离线评测,以本协议为框架。

## Consequences

运行器缺省 `--runs` 为 3,run 记录可携带接缝报告的用量;门禁接受并校验这些字段。oa-answer 观测节点与检索探针工具留待 B4 批次,按 2026-10-16 裁决(议题 甲8 / 丙2)执行;在它们落地之前,B4 对比记为「尚未运行」,而不是薄跑充数。
