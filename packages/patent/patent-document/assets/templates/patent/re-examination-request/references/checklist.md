# 复审请求书 — 自查清单（Checklist）

> 输出定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 案件信息表填满（申请号、发明名称、请求人、驳回决定文号与日期、复审期限、提出日期）
- [ ] 复审期限 = 送达日 + 3 个月，由工具计算并写入
- [ ] 驳回决定要点摘录与原文一致（文号、日期、理由顺序）
- [ ] 复审理由逐条针对驳回理由回应，无遗漏
- [ ] 修改对照表每行都有「修改依据」（原文件页码）
- [ ] 修改仅采用法定方式（删除/合并/缩小范围），无新增特征或扩大范围
- [ ] 法条引用（专利法、实施细则）有出处并复核
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 请求事项与复审理由一一对应
- [ ] 证据支持引用对比文件公开号与页码
- [ ] 超出期限的请求附恢复窗口说明

## P2 — 锦上添花

- [ ] 提供 `.md` 源稿便于后续修订
- [ ] 导出 PDF 后抽查表格是否跨页断裂
