# 实用新型/外观设计专利权评价报告 — 引用日志规范

> 与 `patentability-opinion` 模板共享同一四字段引用纪律，本节为其在评价报告场景下的具体化。

## 四字段

每条关键断言必须包含：

1. **断言 / 结论**：例如「对比文件 1 公开权利要求 1 的特征」。
2. **来源类型**：相关文件（现有技术）／客户提供／模型推断／假设。
3. **来源名称**：文献号、原评价报告编号等。
4. **引证定位**：说明书段号 `¶XXXX`、附图编号、相关权利要求编号。

## D 表即引证来源

评价报告的 D 表就是正文引证的登记点。每条对比文件必须在 D 表写全：

| 字段 | 说明 |
|---|---|
| 类型 | X / Y / A / E / R，含义见图例 |
| 文献号 | 公开号或书名（含期刊卷号/期号） |
| 公开日 | 公开/出版/发行日期 |
| 分类号 | IPC/CPC 分类号 |
| 相关部分 | 引用的说明书段号或附图编号 |
| 相关的权利要求编号 | 该文件影响的本次评价的权利要求编号 |

## 规则

- 正文每处「对比文件 N（公告号：…）」对应 D 表一行，两处文献号一致。
- 文献号、公开日、段号必须真实存在；转制件保留原报告值，模拟件不得编造。
- 无法溯源的边界判断降级为「模型推断」或「假设」。
