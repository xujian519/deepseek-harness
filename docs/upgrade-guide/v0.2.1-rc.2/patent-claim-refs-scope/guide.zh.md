# 权利要求引用关系覆盖长引言与概括引用

[English](guide.md) | 中文

## 变更

`deriveClaimRefs`（以及 `claim-chart` 原子生成的全部权利要求图表）的引用识别发生变化：

- 引用语不再只在前 40 个字符内查找。带前缀的引用语（`根据权利要求1`、`如权利要求2`、`按照权利要求1-3`）在权项正文任意位置生效，包括特征部分，因此引言较长的从属权项不会再被报成独立权项。
- 不带前缀的 `权利要求1所述` 仍只在引言部分生效——`其特征在于` 之前，或（权项无特征部分时）第一句以内。正文中途的转述（如 `装配权利要求1所述的装置`）不会建立引用关系。
- 概括引用（`前述权利要求中任一项`、`上述权利要求之一`、`权利要求中任一项`）展开为全部在前权项，而不再被忽略。

这一变化影响法律结论而不只是展示：覆盖与新颖性判定会通过 `referencedClosure` 纳入被引用权项的全部技术特征，原先被静默当作独立权项的权利要求现在会继承其引用的权项限定。

## 迁移

1. 对引言较长或含概括引用的权利要求书重新推导引用关系。已落盘的权利要求图表若把此类权项标为 `independent`，其结论是旧的；复用覆盖结论前请重新生成图表或更新其 `claims` 行。
2. 若权项只是在方法步骤中引用另一权项（例如 `按权利要求1所述进行装配`），保留无前缀写法：带前缀的写法（`根据权利要求1`）无论出现在哪里都按从属引用处理。
3. 确认：`pnpm exec vitest run packages/patent/patent-core` 通过，且从属权项的权利要求图表在 `refersTo` 中列出其引用的权项。
