# 新颖性与创造性分析

对目标权利要求先做新颖性判断（逐篇单独对比），具备新颖性后再做创造性判断（三步法）。检索先于结论：分析前先完成 patent-prior-art-search 并引用对比文件。

## 必查清单（先查再分析）

- 用 patent_wiki_search 查审查标准卡片：新颖性单独对比、创造性三步法、所属领域技术人员。
- 用 patent_case_search 查相似在先决定的论证细节与证据认定。
- 用 patent_kg_query 沿知识图谱追查裁判规则。
- 用 web_fetch 核验 A22.2 / A22.3 法条原文；法条引用不得凭记忆。

## 新颖性分析（A22.2，单独对比）

1. 特征分解：将权利要求分解为最小技术特征单元，标注类型（结构/方法/参数/材料）。
2. 三级解构：表面特征 → 技术手段（工作原理/结构/连接关系/控制逻辑）→ 技术效果（作用机理/量化指标）。
3. 对每篇对比文件做公开充分性四分类：明确公开 / 隐含公开 / 未公开 / 模糊记载。
4. 逐篇单独对比：以每一篇对比文件为独立单位，判断是否存在一篇公开了全部技术特征；不得跨文件组合特征。
5. 区别特征本质识别：区分表面区别 / 功能区别 / 原理区别。
6. 结论：一篇覆盖全部特征 → 缺乏新颖性；否则具备新颖性（继续创造性评估）；不确定处标注置信度。

## 创造性分析（A22.3，三步法）

1. 确定最接近的现有技术（D1）：同领域、公开特征最多、技术问题最接近；多候选时逐一试判。
2. 确定区别特征与实际解决的技术问题：实质对比，技术问题表述不得包含解决手段；客观确定，不以发明人声称的问题为准。
3. 判断技术启示：区别特征是否公知常识、对比文件是否有结合启示、是否存在反向教导；多篇结合必须论证组合动机。

辅助判断因素（非充分非必要条件）：预料不到的技术效果（量化数据支撑）、长期渴望未解决的技术难题、克服技术偏见、商业成功（由技术特征而非营销导致）。

创造性等级：高（显著进步+非显而易见+预料不到效果）/ 中（明显进步+非显而易见）/ 低（一定进步）/ 无（显而易见）。

## 收口校验

分析完成后调用 patent_workflow（manifestId 为 patent_novelty_v1 或 patent_inventiveness_v1）按阶段收口；确定性规则门（rule_check，默认 patent 域）通过方可交付。

## 关键原则

- 单独对比不跨文件组合；区分技术特征与技术效果（效果相同不等于特征被公开）。
- 所有对比结论附引用来源（对比文件号 + 段落/附图位置）；不确定标注置信度。
- 结论不得使用绝对化表述（绝对/一定/百分百）。

## 输出结构

目标专利基本信息、权利要求特征分解表、对比文件清单、逐文件单独对比表、新颖性结论（附置信度）、创造性三步法分析（最接近现有技术/区别特征与技术问题/技术启示 + 等级）。

## 质量门禁与人工确认

报告自查单独对比、特征/效果区分、来源引用；分析结论经 ask_user 人工确认后交付；附免责声明。
