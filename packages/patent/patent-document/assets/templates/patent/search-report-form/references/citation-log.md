# 表格式专利检索报告 — 引用日志规范

> 与 `patentability-opinion` 模板共享同一四字段引用纪律，本节为其在检索报告场景下的具体化。

## 四字段

每条关键断言必须包含：

1. **断言 / 结论**：例如「D1 公开 F1」、「R2 命中 184 篇」。
2. **来源类型**：相关文件（现有技术）／数据库记录／客户提供／模型推断／假设。
3. **来源名称**：文献号、数据库名、检索报告编号等。
4. **引证定位**：说明书段号 `¶XXXX`、检索式编号 `R1`、相关权利要求编号。

## D 表即引证来源

检索报告的 D 表就是正文引证的登记点。每条对比文件必须在 D 表写全：

| 字段 | 说明 |
|---|---|
| 类型 | X / Y / A / E / R，含义见图例 |
| 文献号 | 公开号或书名（含期刊卷号/期号） |
| 公开日 | 公开/出版/发行日期 |
| 分类号 | IPC/CPC 分类号 |
| 相关部分 | 引用的说明书段号或附图编号 |
| 相关的权利要求编号 | 该文件影响的权利要求编号 |

## 规则

- 公开号、段号必须真实存在；不得凭记忆编造。
- 检索式命中数不写「若干」「大量」等模糊词。
- 无法溯源的边界判断降级为「模型推断」或「假设」。
