# 复审请求书 — 引用与来源规范

> 复审请求书引用驳回决定、原申请文件与对比文件；所有引用需可定位、可复核。

## 来源类型

| 来源类型 | 用途 | 徽标 |
|---|---|---|
| 官方文件 | 驳回决定、审查报告 | `badge-evidence` 证据支撑 |
| 现有技术 | 对比文件、证据 | `badge-evidence` 证据支撑 |
| 客户提供 | 请求人信息、修改意图 | `badge-client` 客户提供 |
| 模型推断 | 争辩策略表述 | `badge-model` 模型推断 |

## 规则

- 驳回决定文号、日期、理由顺序必须与驳回决定原文一致。
- 对比文件引用给出公开号与页码；证据支持必含来源路径。
- 法条引用（专利法/实施细则/审查指南）供校核用，正式提交以现行法条为准。
- 引用原申请文件时给出页码或段落，修改依据必须可追溯到原文本。
