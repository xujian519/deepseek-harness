# 内部无效宣告分析意见 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。本件为**内部件**：可载引用日志、逐权项结论分档与缺口披露；若要对外提交，须改用 `invalidation-opinion`（专利无效宣告请求书）模板另行出件，不得把本件及其内部记录直接对外发送。

## P0 — 必须通过

- [ ] 文书结构完整且顺序正确（`conventions.md §1` 的七节 + 不带中文数码的「分析结论」）
- [ ] 章节编号唯一、按序，且只出现在章节级标题（h2）上
- [ ] 案件信息表填满（涉案专利号、专利名称、授权公告日、专利权人、委托方 / 委托人、分析日期）
- [ ] 全部槽位填满（含 `grounds-body` 与 `gaps-body` 两个结构生成槽位的内容）
- [ ] 无效理由节的节标题与四段式小标题由结构与法条生成，正文未手写小节标题
- [ ] 每个无效理由按「事实认定 → 证据分析 → 法条适用与结论」四段式组织
- [ ] 法条引用精确到条款号；未把单一性（A31条第1款）作为无效理由提出
- [ ] 逐权项结论表覆盖全部目标权项，每项写明结论档、法条路径与依据风险
- [ ] 每项从属权利要求的无效理由与其引用的权利要求使用同一法条路径（`conventions.md §2.1`）
- [ ] 对比文件公开日早于涉案专利优先权日 / 申请日；抵触申请单独标注
- [ ] 证据清单逐条登记标识与日期：出版物写 ISBN 与出版年月，原始申请文件在标识列写「—」，标识列不留空（`invalidation-opinion/references/conventions.md` §4.1）
- [ ] 证据编号两侧对齐：正文引用的编号全部登记在表 2，表 2 登记的编号全部在正文引用过（含第六节引用日志与第七节缺口披露里的引用），编号列无空行（渲染器的证据编号核对零告警）
- [ ] 每条关键断言在引用日志中有对应行，且引用日志与正文断言一致
- [ ] 无编造公开号、日期、段号；未核对原文的证据已降级为「模型推断」或「假设」并列入第七节
- [ ] 缺口与待补事项写明待补材料、责任与对分档的影响，含最坏情形
- [ ] 正文不出现「请求宣告……无效」一类对外请求句
- [ ] 免责声明与密级完整，品牌变量已注入
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 无效理由之间不重复、不矛盾
- [ ] 无以「附加技术特征被公开」为由认定从属权利要求不具备新颖性的表述
- [ ] 结论分档与理由节的证据覆盖一一对应，无据可依的权项未被标为「可无效（证据充分）」
- [ ] 引用日志的来源类型与徽章取值符合 `references/citation-log.md` 的对照表
- [ ] 表格数字列使用 tabular 数字，编号列用等宽体
- [ ] 分析范围一节写明分析基础、时间界线与结论口径

## P2 — 锦上添花

- [ ] 同时产出 `.md` 源稿与 `.pdf`
- [ ] 导出 PDF 后抽查表格是否跨页断裂
- [ ] 把待补检索与待核原文整理成案卷清单，并在下一版更新分档
