# Agent Note：上游 v0.1.3-alpha.1 同步与 session-format-v2 流模型

状态：已实现

[English](2026-09-06-upstream-v0.1.3-alpha.1-sync.md) | 中文

## 问题

fork 在 v0.1.2-rc.1 同步后跟踪上游；上游 master 前进到 `d347e70390`（发布为 `dsh-v0.1.3-alpha.1`，共同祖先 76fda72979 相对上游领先 229 个 commit，fork 领先 323 个 commit）。上游的主要特性是 session format v2：`assistant/chunk` 事件被移除，改为携带内嵌 `AssistantStream` 的 `assistant/message` 事件；JSONL 持久化后端新增跨进程写所有权租约与格式迁移；同时以通用的 client 文件上传服务收拢附件准入。

## 决策

- **分片事件淘汰。** `assistant/chunk` 不再存在；usage 与流内容落在 `assistant/message` 信封（`usage`、`stream`）。fork 的 `scripts/token-economy-baseline.ts` 及其 spec 中的 `usageOf` 移除 chunk 分支；测试夹具改为构造带 `stream` 数组的 `assistant/message` 事件。
- **会话格式版本。** `SESSION_FORMAT_VERSION` 为 `2`；`SessionHeader.version` 是字面量类型 `2`。把写死 `version: 0` 的会话头与夹具更新为 `2`（self-evolve-basic 测试、token-economy spec）。
- **`SurfaceIntent<T>` 加 `AppendOptions`。** 上游把 `SurfaceIntent` 改为按 surface 事件类型泛型，使 v2 的 `assistant/message` 不能引用顶层源事件（`sourceEventSeqs?: never`）。fork 保留其非 surface 的 `AppendOptions` / `ignorable` 追加标记（patent-teams 仍追加 `{ ignorable: true }`）；`Session.append` 签名与 JSDoc 同时保留两者。
- **删除 packed chunk rows。** 上游删除了 `packages/core/session/src/chunk-rows.ts`（旧 packed-run 格式被 v2 取代）。fork 仅把 `isRecord` 沉到 `dsh-value`；删除该文件及其导出，并移除 `tsconfig.base.host.json` 中的 `dsh-session/chunk-rows` 别名。
- **文件上传与 per-face 分离。** 新增 `client/file-upload`、`session-format`、`session-format-catalog` 以及 v0-to-v1 / v1-to-v2 迁移包。Host 聚合 `tsconfig.base.host.json` 增加新包别名、移除过期 chunk-rows 别名；`tsconfig.host.json` 引用新的 session-format 子项目。
- **版本对齐。** test-support 与 session 的 `package.json` 依赖按各自源码 import 同时保留 fork 的 `dsh-value`（`isRecord`、`isENOENT`）与上游的 `session-format*` 包。
- **文档。** 重新生成各类 catalog（config-catalog、persistence-catalog、module-graph、capability-seams、event-producer-consumer、cordis api-catalog、known-event-types）、lockfile，并重录受影响的双语文对；agent note 的 CI 段落保留 fork 的 `workflows-disabled/` 路径，同时采纳上游第五个 macOS x64 构建目标。

## 后果

fork 共享上游的 session-format-v2 词汇（内嵌 assistant 流、`assistant/message` 承载的 usage、`version: 2` 会话头）与写租约 / 迁移后端，同时保留自己的 `ignorable` 追加标记和 `dsh-value` 下沉助手。`tsc -b tsconfig.host.json`（Host 类型检查）本地通过；`tsdown` 打包步骤对根解决方案包 `@deepseek-ai/dsh-root` 报出 entry 解析失败，属于独立的构建基础设施问题。

Host 类型检查（`tsc -b tsconfig.host.json`）在 macOS 本地通过。双语文对已重录（`verify-translation-pairing`）。Linux lane CI 仍是本次合入的平台记录运行。
