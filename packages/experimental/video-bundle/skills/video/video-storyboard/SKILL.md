# Video Storyboard（分镜与资产）

分镜是可执行单元，不是文学描述。每个镜头必须能被一次图像或视频生成调用执行。

## 镜头字段

| 字段 | 要求 |
|---|---|
| `id` | `s01`、`s02`，项目内唯一 |
| `index` | 从 1 开始的顺序 |
| `prompt` | 主体 + 动作 + 环境 + 光线 + 景别 + 风格；一段话，不堆关键词 |
| `duration_sec` | 2–6 秒；总时长对齐 brief |
| `status` | 初始 `draft` |
| 台词 | 说话人、文本、情绪；写入镜头备注或脚本文件 |
| 参考资产 | 角色/场景/道具 id，先有资产再有镜头 |
| 关键帧 | 首帧路径；需要运动控制时再加尾帧 |

## 流程

1. 写脚本：logline → 节拍 → 分场 → 台词。保存 `script.md`。
2. 建资产表：角色（正/侧/背/表情）、场景、道具；每个资产一段固定 prompt 与参考图路径。
3. 用 `video_project init` 创建项目，记下返回的 `project.json` 路径。
4. 逐镜调用 `video_project` 的 `upsert_shot`，把镜头写入项目。
5. 与用户确认镜头表与预算估算，再进入 `video-generate`。

## 检查清单

- [ ] 镜头总时长与 brief 目标偏差不超过 10%
- [ ] 每个镜头有可执行的画面 prompt 与时长
- [ ] 角色/场景在多个镜头中复用同一资产 id
- [ ] 项目文件中的镜号连续、无重复
- [ ] 用户已确认分镜与预算
