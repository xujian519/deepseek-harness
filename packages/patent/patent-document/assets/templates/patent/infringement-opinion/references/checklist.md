# 侵权比对意见书 — 自查清单（Checklist）

> 输出定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 案件信息表填满（专利号、发明名称、专利权人、被控产品、委托方立场、报告日期）
- [ ] 权利要求 1 全文为授权公告原文，未改写
- [ ] 被控物特征清单覆盖被控产品全部相关特征，特征号连续
- [ ] 全面覆盖比对表逐特征一行，结论明确（相同/等同/未落入）
- [ ] 等同分析表三要素（手段/功能/效果）齐备
- [ ] 结论句回答「被控产品/方案是否落入保护范围」
- [ ] 证据附录列出路径（公开号/链接/文件路径），来源类型徽标正确
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 禁反言、捐献、现有技术抗辩等限制因素单独列出
- [ ] 与报告方立场冲突的反证未被屏蔽
- [ ] 数值/参数比对引用工具计算或原文出处

## P2 — 锦上添花

- [ ] 提供 `.md` 源稿便于后续修订
- [ ] 导出 PDF 后抽查比对表是否跨页断裂
