# 2026-09-11

## 桌面端 UI/组件审阅（首次）

产出报告：`.workbuddy/reports/2026-09-11-desktop-ui-review.md`

**审阅范围**：`packages/client/*`（49 个 UI 包、142 个 CSS Modules / 27,740 行、119,511 行 TSX）+ `apps/desktop` Electron 壳。
注意：桌面端 UI 不在 `apps/desktop`，那里只是 Electron 壳（含唯一自有 UI 面 `renderer/plugin-manager.*`）；真正的 UI 全在 `packages/client/ui-*`。

**核心结论（量化）**：设计系统只完成"配色"一半。
- 颜色：三层 token（static→alias→specific）真实落地，深浅双主题完整对位，约 85% 采用
- font-size：451 声明仅 4 走 composite token（0.9%）
- transition 时长：119 仅 6 走 `--ds-transition-duration*`（5%）
- border-radius / spacing / z-index：**无 token**（23 个取值 / 1366 个 px 值 / 28 个魔数）

**已独立复算确认的关键缺陷**（对比度按 WCAG 相对亮度公式复算）：
- `label-dimmed` 浅色 1.26:1、深色 1.90:1（design-platform.css:202/295）
- `label-caption` 浅色 2.14:1；`label-tertiary` 浅色 3.70:1（用于 330 处）
- 主按钮是**中性近黑**而非品牌蓝：`--dsw-alias-brand-primary` → `neutral-bluish-1000`（:179）
- 品牌强调色三分裂：`state-business-primary`(105 处) / `brand-primary-new-colorprimary-new-color`(仅 15 处，在 trajectory+dockkit) / 主按钮近黑
- 全客户端**无任何全局 `:focus-visible` 规则**；`ui-primitives` 的 Button/Input/Menu/Tooltip/Modal/Tag/Pill focus-visible 计数全为 0
- `Button.module.css` 的 `transition` 计数为 0（hover 瞬时跳变，primary 无 active 态）
- `createLayoutStore`（ui-layout/stores.ts:76-130）**无 persist**，而 ui-conversation/stores.ts:23 有 → 三栏布局重启即丢
- `apps/desktop/src/main.ts:90-104` 的 BrowserWindow **无 titleBarStyle/frameless/transparent/vibrancy**；已写好的 `better-sidebar/src/client/wco.ts`、`titlebar-strip.ts` 是死代码
- 全客户端 `backdrop-filter` **仅 9 处**，4 处是 `blur(2px)` 遮罩 → "毛玻璃"只存在于意图中
- `Modal.tsx:41-48` 只有 Esc，**无焦点陷阱、无初始聚焦、无焦点归还**，但写了 `aria-modal="true"`（声明与行为不一致）
- `--dsw-font-m-18` 实际值 16px/28px，命名与值不符（gradient-shadow-text.css:193）
- 浮层列表 4 套并行实现（Menu/PopupSelectView/MenuView/ModelSelect），`MenuView.tsx` 无 Escape；`ModelSelect.tsx:130` 用 `jscpd:ignore-start` 注释**压制了克隆检测**
- 生产代码无 `<main>` landmark、无 `<h1>`

**给出的建议**：三阶段路线图（止血 1 周 → 统一 2-3 周 → 提升 3-4 周），并强调阶段二**必须配 CI 闸门**（禁止裸 font-size/border-radius/z-index/硬编码色值），否则 P1 问题会退化回现状。报告第 7 节给出可直接落地的 8 组 CSS token 补丁（含新增 `neutral-bluish-650 = rgb(112,117,123)` 补齐 4.5:1）。

**值得肯定**（写入报告以保持客观）：`Tag`/`Pill` 边界划分清晰且注释完整；`columns.ts` 布局求解为纯函数+命名常量；`AppFrame` 拖拽用 pointer capture + rAF 且拖拽时主动关过渡；`aria-*` 1221 处、纯图标按钮缺 label 数量为 0。
