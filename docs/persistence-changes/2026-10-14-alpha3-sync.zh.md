## 概述

<a id="compatibility"></a>
## 兼容性

same-version。相对前一条记录的差异是消息载荷上新增的、仅用于归因的 source kind（`patent-rule-gate`、`self-evolve`、`sidechat`、`patent-teams-report`）：它们已由 `2026-10-12-patent-rule-warn-context` 为本 fork 登记过，读者的 kind 分支也早已处理。判别字段语义未变，没有字段变成读取时必需，早于这些 kind 的读者仍能渲染承载它们的消息。

<a id="verification"></a>
## 验证

`pnpm run verify-persistence-changes` 报告以本记录为末端的线性历史，`pnpm run doc-sync` 中的持久化门禁通过。四个共享 root 通过把上游记录的 previous 指向 fork 在同一 root 上的最后一条记录完成线性化，因此每个 root 恰好只有一个后继。
