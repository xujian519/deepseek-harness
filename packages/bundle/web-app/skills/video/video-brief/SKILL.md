# Video Brief（视频规格）

先把规格定死，再动脚本与分镜。规格不完整不进入生成阶段。

## 必须捕获的字段

1. **内容类型**：短视频 / 口播解说 / 歌曲 MV / 视频切片。
2. **平台与画幅**：抖音/视频号/小红书等；`9:16`、`16:9` 或 `1:1`。
3. **时长**：目标秒数；单镜头建议 2–6 秒，总镜头数按目标时长估算。
4. **分辨率**：默认 `720p`；需要 `1080p` 时先估算成本。
5. **预算**：默认 50 元；单次生成超过 10 元必须让用户确认。
6. **声音**：是否需要配音、BGM、字幕；字幕默认烧录。
7. **素材授权**：BGM、歌曲、切片源视频由谁提供、授权范围；没有授权不生成。
8. **AI 标识**：是否需要可见水印；默认写元数据并在清单中标注。
9. **成功标准**：交付时如何判定完成（时长、画幅、字幕、音轨、成本）。

## 流程

1. 从用户原话提取已给字段；缺口用 `ask_user_question` 一次问清，不要逐条追问。
2. 把预算与时长写成数字，后续传给 `video_project init`。
3. 输出 `brief.md`，含上述字段与一页以内的创意方向。
4. 与用户确认后进入 `video-storyboard`。

## 检查清单

- [ ] 内容类型、平台、画幅、时长、预算全部非空
- [ ] 素材授权已记录；没有授权时明确说明不会生成
- [ ] 成功标准可验证（数字或明确产物）
- [ ] 用户已确认 brief
