# 审查意见答复 / 意见陈述书 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md` 配套。

## 1. 文书结构（固定顺序）

1. 页眉（所名 + 密级）
2. 文书抬头（类型徽标 / 标题 / 答复编号）
3. 案件信息表（申请号 / 发明名称 / 通知书编号 / 发文日 / 答复日期 / 申请人或代理人）
4. 一、总体立场
5. 二、本次修改（修改对照表 + 修改后独立权利要求全文）
6. 三、本案事实（3.1 申请文件记载的事实 / 3.2 对比文件公开的事实）
7. 四、适用规则
8. 五、意见陈述（5.1 新颖性 / 5.2 创造性 / 5.3 其他争点）
9. 六、其他缺陷的处理
10. 七、证据与引用（7.1 证据清单 / 7.2 引用日志）
11. 八、结论与请求
12. 落款 + 免责声明 + 页脚

## 2. 论证骨架：事实 → 规则 → 论证

全文按三段推进，缺一段即为不合格：

1. **事实**（第三部分）。只写"本申请记载了什么、对比文件公开了什么"，逐项编号（F1…／P1…）并注明出处（权项号、说明书节次与页码行号、对比文件段落）。**每项不超过两句**，只保留与争点相关的特征；不带评价、不带结论。
2. **规则**（第四部分）。逐条列明本案据以论证的规则，编号 R1…，注明法条条款号或《专利审查指南》节号。
3. **论证**（第五部分）。每条论证回指事实编号（F/P）与规则编号（R），按争点组织。

**禁止把评价写进事实部分**：「本发明与对比文件有本质区别」是论证结论，不是事实。事实与评价分离，既是论证清晰的前提，也是审查员复核的便利。

## 3. 组织单元是争点，不是审查意见编号

- 论证按法律命题分节（新颖性／创造性／其他争点），**不按通知书的审查意见项号分节**。
- 审查意见项号只在需要让审查员定位时以括注出现，例如「（审查意见第 3 项）」；不得作为小节标题。
- 存在多个独立争议（如同时涉及 26.3、26.4、22.3）时，仍按争议主题分节，不按通知书顺序铺陈。
- 形式缺陷（笔误、附图标记、摘要撰写、用词）一律收入第六部分「其他缺陷的处理」，逐项列处理方式与依据，不与实体论证争篇幅。

## 4. 法条与指南引用

- 新颖性：《专利法》第 22 条第 2 款。
- 创造性：《专利法》第 22 条第 3 款；判断方法引《专利审查指南》第二部分第四章第 3.2 节、第 3.2.1.1 节。
- 修改依据：《专利法实施细则》第 57 条第 3 款（针对通知书指出的缺陷进行修改）。
- **条号必须核验后引用**，不得凭记忆书写；旧版条号（如 2010 年细则第 51 条第 3 款）应换算为现行条号。
- 随包索引对《专利审查指南》**只登记节号、未转录原文**，因此逐字引用指南原文时须另行提供经核验的文本来源，否则只引节号与主题。
- 无来源支撑的断言删除，不降级为模糊表述。

## 5. 事实的 pin-cite 精度

- 本申请：权项号 / 说明书节次 / 页码行号。
- 对比文件：文献号 + 权利要求项号 / 说明书段落号或页码行号 + 附图标记。
- 结构性定位（"说明书'发明内容'部分""实施例 1"）只用于工作稿；**正式稿必须落到页码行号**。

## 6. 权利要求修改标注

- 新增内容用下划线 + 加粗（`<span class="added">`）。
- 删除内容仅在修改对照表中用删除线（`<span class="deleted">`），正式权利要求文本中不保留删除线。
- 修改后的独立权利要求必须全文呈现，不能只写「参见修改对照表」。

## 7. 视觉与版式纪律

- 沿用 `assets/templates/patent/tokens.css` 品牌变量；agent 不改样式。
- `claim-text` 区块用于权利要求全文，左侧 accent 竖线标识。
- 表格数字列使用 `tabular-nums`。

## 8. 正式提交件的载体（所外）

本模板产出的 HTML/PDF 是**所内复核稿**。向国家知识产权局提交时使用官方标准表格：

- 载体：`100012 意见陈述书`（①著录项、②陈述事项、⑤附件清单、⑥签章）+ `100014 附页`（正文）。
- 表格 ② 栏写称呼与引子（如「××审查部 ××（审查员代码）审查员：您好！根据您的审查意见，现答复如下：」）；正文转入附页时写「下转附页第②栏」。
- 正文较短（仅同意修改、无实体争辩）时直接写在 ② 栏，不启用附页。
- 附件清单须列明份数与页数，且与实际提交页数一致。
- 本地模板库：`~/.dsh/patent-ops/templates/cnipa-标准表格/`。

## 9. 品牌契约注入点

同 `assets/templates/patent/DOCS.md` 与 `tokens.css`。抬头所名、密级、免责声明由 CSS 变量注入。
