# 审查意见答复 / 意见陈述书 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 文书结构完整且顺序正确（八部分，见 `conventions.md` §1）
- [ ] 案件信息表填满（申请号、发明名称、通知书编号、发文日、答复日期、申请人/代理人）
- [ ] 总体立场明确，列出全部答复要点
- [ ] 第三部分只有事实、没有评价；每项事实不超过两句且带出处
- [ ] 第四部分逐条列明规则（R1…），条号已核验
- [ ] 第五部分每条论证回指事实编号（F/P）与规则编号（R）
- [ ] 论证按争点分节，未按审查意见项号分节；项号仅作括注
- [ ] 形式缺陷收入第六部分清单，未与实体论证混排
- [ ] 权利要求修改对照表包含修改前/修改后/修改依据三列
- [ ] 修改后的独立权利要求全文呈现，新增部分用下划线加粗标注
- [ ] 对照表与全文两份都在且对得上：表 1 登记过的独立权利要求，全文里能查到（`conventions.md` §11，双份不合并）
- [ ] 证据清单与引用日志两份都在且对得上：日志里引用的 D 编号都登记在清单（同上）
- [ ] 三张表都没有空表头：不存在「只有表头没有数据行」，也不存在「数据行整行是 `________` 占位」
- [ ] 法条引用精确到条款号，无"相关规定"式模糊表述
- [ ] 证据清单包含审查员引用的全部对比文件
- [ ] 每条关键断言在引用日志中有对应行
- [ ] 无编造公开号、日期、段号
- [ ] 免责声明与密级完整，品牌变量已注入
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换；签署栏「代理人：」「日期：」是签名线，由人工签署时填写，不算占位泄漏）
- [ ] 无空节：通知书未提出的争点不设小节，该节整节删除，也不留「本案不涉及新颖性」式占位句（`conventions.md` §10）
- [ ] 正文无模板指导语（「本部分应当说明…」「以下逐项分析…」类句子），每段首句直接给结论
- [ ] 全篇正文在篇幅预算内：剔除空白后统计可见字符（不含表格与权利要求全文），总字数 ≤ 4000，且每一节不超 `conventions.md` §10 预算表对应行

## P1 — 应当通过

- [ ] 争议点覆盖通知书全部实体理由，无遗漏（形式缺陷由第六部分清单兜底）
- [ ] 事实与证据含逐字摘录 + pin-cite，正式稿已落到页码行号
- [ ] 逐字引用的指南原文经 `law_verify` 核验落在所引节及其子节内，且不是 2026 年版已修改的节
- [ ] 修改依据与论证中的技术问题一致
- [ ] 表格数字列使用 tabular 数字
- [ ] 引用日志与正文断言一致（日志是断言溯源、清单是材料登记，两份互不改写）

## P2 — 锦上添花

- [ ] 同时产出 `.md` 源稿与 `.pdf`
- [ ] 导出 PDF 后抽查权利要求区块是否跨页断裂
- [ ] 如需向国家知识产权局提交，另按官方 100012 表格 + 100014 附页出件（口径见 references/conventions.md §8）
