# 现有技术检索（可复用例程）

检索先于结论。任何新颖性/创造性判断必须先完成检索并引用对比文件。本技能是**可复用例程**：从任意场景（交底书理解 / 新颖性 / 创造性 / 无效 / 答复 / 侵权比对）调用，产出标准化的检索报告 + 可溯源的对比文件集。

## 0. 输入与输出
- **输入**：技术主题 / 交底书要点、目标 IPC（推荐）、目标申请日 / 优先权日、（可选）申请人。
- **输出**：
  - `01-检索/YYYY-MM-DD_<主题>.md`（检索式逐条 / 各通道命中 / 去重 / 遴选理由 / 未覆盖清单）
  - `02-对比文件/D<序号>_<公开号>.pdf`（+ txt 留存原文）
  - 证据附录：每条对比文件的 `公开号 + 公开日 + 引用段落 + source_path`（双源互证）

## 1. 例程步骤
1. **提取检索要素**：从交底书 / 方案提取技术关键词 + 同义词（中英）+ **IPC 分类号**（用 ipc 分类树 `:8001/api/cnlaw/ipc/sections 与 .../tree?parent=<IPC 代码>（如 H01M）` 辅助）+（可选）申请人 / 发明人。
2. **构建检索式**：多组（关键词 + 分类号 + 布尔），**CN/EN 双轨**；例：`(关键词 OR 同义词) AND IPC=<类>`，若干组覆盖不同语义。
3. **检索式经 ask_user 确认**（或至少说明取舍理由）。
4. **分通道执行**（按 §2 通道策略）。
5. **合并去重**：各通道命中按公开号去重；记录每条来源 / 公开日 / 法律状态 / 摘要或权要；下载或记录原文。
6. **遴选对比文件编号 D1/D2/…**：按 同技术领域 + 公开特征最多 + 所要解决技术问题最接近；重命名 `02-对比文件/D<序号>_<公开号>.pdf`，pdf→txt 留存原文。
7. **标注未覆盖**：列出未覆盖的分类号 / 日期范围 / 数据库。

## 2. 通道策略（优先 + 回退）

| 通道 | 覆盖 | 用法 / 技能 | 备注 |
|---|---|---|---|
| **CNIPR** | 中国发明公开/授权、实用新型、外观设计、港台、美/日/EPO/WIPO 等 | `cnipr-search-download`（`search.cnipr.com`，ego_browser 登录态；技能在 `~/.sati/skills/cnipr-search-download` 或 `~/.agents/skills/cnipr-search-download`） | **CN 专利检索 + 单篇全文 PDF（直链必须 `http://` 前缀，`https` 超时）+ 单篇著录项 .xls（L1 免费）**；概览页 PDF下载/批量著录/XML全文 为 VIP 专属 |
| **CNIPA** | 中国官方审查信息 / 法律状态 | `cnipa-query` / CNIPA PSS（`pss-system.cponline.cnipa.gov.cn`） | 官方；用于**法律状态 / 著录项权威核验**，作为双源交叉的一源 |
| **Google Patents** | 外国 / 全球专利 | `google-patents-search`（ego_browser，免代理） | **外国/全球**；结果落盘 md；补充 CNIPR 未覆盖的外国专利 |
| **web_search** | 期刊 / 论文 / 非专利文献（NPL） | `web_search` | 辅助现有技术 |
| **patent_search** | 本地专利库（nuo 引擎，与 Google Patents 不同通道） | `patent_search` / `patent_metadata` | 备选；本地库不可达/无数据时可能空，如实标注 |

**主路径**：CN 发明/实用新型 → **CNIPR**；官方核验 → **CNIPA**；外国/全球 → **Google Patents**；文献 → web_search；本地补充 → patent_search。
任一通道空或不可达 → **明示该通道未覆盖**；不得据其空结果下新颖性/创造性结论。

## 3. 硬规则
- **覆盖即证据，未覆盖即声明**：未覆盖领域（分类号 / 日期 / 数据库）必须显式列出；"未检索到"≠"不存在"，未覆盖不得下新颖性/创造性结论。
- **双源交叉**：关键事实（公开日 / 法律状态 / 申请人）在两个独立源（CNIPA + Google Patents，或 CNIPR + 其一）互证；有 `web_fetch` 时打开原文核验，不信摘要。
- **对比文件边界**：每条公开日须严格早于目标申请日 / 优先权日；只引用确证存在的对比文件，不编造公开号/日期。
- **CNIPR 取全文**：PDF 直链只能从**详情页**抽，不可按公开号猜测 `PDF_PID`；一律 `http://` 前缀打开（`https` 会超时）。

## 4. 复用要点（跨场景）
- **交底书理解**：检索用于判断"技术问题是否已被现有技术解决 / 是否为现有技术"。
- **新颖性 / 创造性**：该例程产出 D1/D2/D3，供三步法逐特征比对（单独对比 / 最接近现有技术）。
- **无效 / 答复**：在既有基础上再检索"针对该权利要求 / 该对比文件"的更精准对比文件或反驳证据。
- **侵权**：检索与权利要求等价的现有技术 / 设计抗辩。

## 5. 质量门禁
每篇对比文件：公开号 + 公开日 + 用途（D 几 + 针对哪一区别特征）+ source_path；报告含检索式、数据来源、检索日期、覆盖范围、遴选理由、未覆盖清单。交付前由 `patent-quality-gate` 复核（证据附录缺失即视为未完成）。
