# 专利诉讼文书 — 引用与来源规范

> 诉讼文书引用涉案专利、侵权事实证据与法条；全部主张须对应证据编号。

## 来源类型

| 来源类型 | 用途 | 徽标 |
|---|---|---|
| 专利文本 | 授权公告、权利要求、审查历史 | `badge-evidence` 证据支撑 |
| 被控事实 | 公证购买、网页证据、发票 | `badge-evidence` 证据支撑 |
| 客户提供 | 当事人信息、损失计算数据 | `badge-client` 客户提供 |
| 模型推断 | 法律适用表述建议 | `badge-model` 模型推断 |

## 规则

- 每项事实主张引用证据编号（证据 1、证据 2…）。
- 侵权依据引用涉案专利的独立权利要求编号与条款原文。
- 法条引用（专利法第十一条、第六十五条等）供校核用，正式提交以现行法条为准。
- 赔偿计算的数据来源（财报、许可合同、费用发票）列出路径，无法取得的标注为假设。
