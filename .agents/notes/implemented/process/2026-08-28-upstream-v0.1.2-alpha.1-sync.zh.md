# Agent Note：上游 v0.1.2-alpha.1 同步与 ApiProxy/Runtime 的移除

Status: implemented

[English](2026-08-28-upstream-v0.1.2-alpha.1-sync.md) | 中文

## 背景

Fork 跟踪的上游停在 `b150a551b8`（v0.1.1-rc.2）。上游 master 前进到 `cd5ef81481`（v0.1.2-alpha.1）：1,079 个提交、5,000+ 文件。本次合并是 fork 例行的 `sync/upstream-v0.1.2-alpha.1` 集成。上游的三处移除切穿了 fork 自有代码，每一处都需要明确的处置，而不是文本层面的冲突解决。

## 处置

**ApiProxy 传输。** 上游删除了 `packages/host/apiproxy`，将宿主访问迁移到采用 one-time-token 网络认证的 Remote gateway。fork 的 electron 选择能力（`packages/client/ui-directory-picker-browse` 桌面 preload 桥）与严格 UTF-8 的 `readFileText` 失去了宿主面：桌面选择桥在客户端侧保留（选择器本身不需要宿主往返），而 `readFileText` 现在是响亮失败的注入，在 `ui-document-studio` 带 `FIXME(port)`——上游没有暴露任何宿主文件读取 Remote。基于网关恢复文件预览是针对上游新连接契约的后续工作，不是要粉饰的合并回归。

**Client Runtime。** 上游移除了 `@deepseek-ai/dsh-client-runtime`；其类型迁往属主包（`ClientContext` 即 Cordis 的 `Context`，会话类型在 `dsh-api-session-controller`，`shallowEqual` 在 `dsh-client-store`）。fork 的 `synapse`、`ui-patent-teams`、`ui-document-studio` 已重新指向。会话视图切换写路径（`registerViewSetter`/`setActiveView`）重新落在上游的 `conversationStore` 上：seat 在挂载时注册 store 的 `setView`，卸载时释放，peer 插件因此仍能把会话跳到自己的视图，而无须触碰 apply 局部的 store 句柄。

**会话事件词汇。** 上游移除了读取侧的 `ignorable` 信封标记（fail-closed 词汇）。合并有意恢复了读取信封上的 `ignorable?: true`：`patent-teams` 写入 ignorable 记录并断言往返，且其事件属于仓内已知类型。`persistence.md` 目前沿用上游措辞；若分歧持续，持久化目录需要一条 fork 注记。

## 较小的处置

- `patent` 与 `document` 两个 agent 预设从 `apps/cli/config/agent-presets/` 移入上游的随附根 `packages/preset/agent-presets/presets/`；roster 期望更新为六项。
- Windows 控制台闪窗修复（`STARTF_USESHOWWINDOW` + `SW_HIDE`）在上游把进程原语移出 `sandbox-windows-acl` 之后，重新落在 `packages/subprocess/win32-process`。
- DSH Patent 品牌重塑经由上游 locale 驱动的品牌（`packages/client/locale`）重新落位，替代其 `localBuildTitle` 结构所取代的组件字面量。
- 专利附图特性（已提交的 `patent-tools` 源码引用附图模块）随合并带入并完成适配：`CallId`→`ToolCallId`、判别式 `ToolExecutionResult` 断言，以及 graphviz 规格模拟中的 `SubprocessOutputRead` 协议字段。
- `examples/opendesign` 保持 fork 自有；上游对 `examples/` 下其余内容的删除被接受，`examples/package.json` 保留（移除失效的 `dsh-acp-demo` 依赖）作为剩余叶子的依赖解析清单。
