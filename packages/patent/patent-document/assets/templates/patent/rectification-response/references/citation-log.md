# 补正书 — 引用与来源规范

> 补正书引用申请文件原文位置与通知书段落；法条引用需给出出处并复核。

## 来源类型

| 来源类型 | 用途 | 徽标 |
|---|---|---|
| 官方文件 | 补正通知书、审查通知 | `badge-evidence` 证据支撑 |
| 客户提供 | 著录项目、申请文件修改意图 | `badge-client` 客户提供 |
| 模型推断 | 修改后的表述措辞建议 | `badge-model` 模型推断 |

## 规则

- 补正通知书文号与日期必须来自通知书原文，不得推断。
- 引用原文位置给出页码与行号（如「第 2 页第 5-8 行」）。
- 法条引用（如专利法第三十三条）供校核用，正式提交以现行法条为准。
- 修正前文书表述中标注的原文位置，替换后须复核一致。
