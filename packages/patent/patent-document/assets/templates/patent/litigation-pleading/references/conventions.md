# 专利诉讼文书 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md` 配套。

## 1. 文书结构（固定顺序）

1. 页眉（所名 + 密级；正式提交版可删除）
2. 文书抬头（类型徽标 / 标题（起诉状或答辩状） / 案卷号）
3. 案件信息表（案由 / 受理法院 / 案号 / 涉案专利号 / 提交日期）
4. 当事人信息表（原告 / 被告）
5. 诉讼请求（起诉状）或答辩意见（答辩状）
6. 事实与理由（含答辩逐项回应）
7. 证据清单
8. 落款 + 免责声明 + 页脚（正式提交版可删除）

## 2. 类型切换

- 标题 `民事起诉状` / `民事答辩状` 由 `doc-kind` 决定；`doc-type` 徽标同步显示。
- 起诉状：第二部分为诉讼请求；答辩状：第二部分为答辩意见（对起诉状逐项回应）。
- 答辩状事实与理由部分以「（三）答辩意见」形式逐项回应起诉状的主张（事实 → 证据 → 法律适用）。

## 3. 当事人信息规范

- 起诉状：原告 = 专利权人/许可人；被告 = 被控侵权人。
- 答辩状：当事人信息仍列双方（被告为提交方）。
- 住所、法定代表人、联系方式以委托方提供或公开登记为准，注明来源。

## 4. 数值与期限

- 赔偿金额 = 计算依据（实际损失/侵权获利/许可费倍数）逐项列示，禁止无来源数字。
- 合理开支（律师费、公证费、取证费）单列。
- 答辩期 = 收到起诉状副本之日起 15 日，用工具计算，禁止心算。

## 5. 内部审稿版 vs 正式提交版

| 元素 | 内部审稿版 | 正式提交版 |
|---|---|---|
| 页眉密级 | 保留 | 删除 |
| 免责声明 | 保留 | 删除 |
| 落款签名 | 保留 | 删除 |

## 6. 视觉与版式纪律

- 沿用 `assets/templates/patent/tokens.css` 品牌变量；agent 不改样式。
- 表格行避免跨页断裂（`page-break-inside: avoid` 已内置）。
- 金额、案号使用等宽字体（`.mono` / `.num`）。

## 7. 品牌契约注入点

同 `assets/templates/patent/DOCS.md` 与 `tokens.css`。抬头所名、密级由 CSS 变量注入。
