# Agent Note: 上游 v0.1.2-alpha.4 同步与可续子代理的重定位

Status: implemented

[English](2026-09-02-upstream-v0.1.2-alpha.4-sync.md) | 中文

## 问题

fork 追踪上游 `dd6322d604`（v0.1.2-alpha.3），其上有 283 个 fork 提交。上游 master 前进到 `4e84901e64`（v0.1.2-alpha.4）：297 个提交、约 2400 个文件，主体是实验性 `code-runtime-python` 后端、破坏性的 `refactor(session)!: distinguish event seqs from log offsets`、sdk/headless/base 默认开启 web fetch、以及 Web UI 性能工作。本次合并要带着 fork 独有包（patent、self-evolve、better-sidebar、synapse、plugin-market）跨过上游的会话 API 破坏与 invariant 伴生层的删除。

## 决策

本次合并即 fork 常规的 `sync/upstream-v0.1.2-alpha.4` 集成。裁定如下：

- **会话 API 破坏。** `session.events` 已删除；fork 消费者改读 `session.snapshotEvents()`，冷恢复的谱系改读 `session.inheritedEventCount` / `header.isSeeded` 而非 `header.seedLength`。Synapse 持久化的线程簿记保留自己的 `seedLength` 字段，恢复时从耐久的 `session/end-seed` 标记（`sessionLiveStart`）取值，因为恢复出的 header 不再携带该长度。
- **可续子代理。** 上游把可续子代理做成一等能力（`startContinuable`、`sendMessage`），并删除了 `SubagentRuntime.followup` 与 `registerContinuableSetup`；provider 契约声明管理器独占组合、「provider 永远看不到 child 的 Agent」。patent-teams 因此删除了成员选型桥（`installMemberSelectionRuntime`/`withPending`/`MemberSelectionRuntime`）：成员的 provider/model 改由创建请求的 `agentOptions` 承载并种入耐久描述符，同时覆盖新组合与冷恢复。`deliverToMember` 与退休成员守卫迁到 `sendMessage`。
- **invariant 伴生层。** 上游删除了大多数 `src/invariant.ts` 伴生及其映射。合并采纳这些删除，包括 `guard/timeout-guard` 的孤儿伴生（关闭 alpha.1 同步 note 的 follow-up 4）。fork 独有包保留自己的伴生；生成别名区域已再生（`gen-tsconfig-paths`），fork 独有的不可推导包别名继续手写在 `tsconfig.base.json`。
- **生成面。** `docs/persistence-catalog` 从源码再生；工具名册、`api-catalog`、`slot-catalog` 取自各自生成器；owner 解决后重录翻译配对。

## 后果

fork 与上游共享 seq/log-offset 会话词汇、描述符种子化的可续子代理、实验性 Python 后端，同时保持每个 fork 独有包对新 API 可编译。成员模型路由现在仅由耐久描述符保证；退休守卫仍拦截对退休成员的直接 `sendMessage` 冷恢复。`pnpm-lock.yaml` 在从 examples 清单移除已删除的 `dsh-tool-subagent-report` 后重生。

## 落选方案

**给子代理运行时打补丁、保留 fork 侧的可续 setup 钩子。** 拒绝：上游把「provider 看不见 child 的 Agent」声明为契约，补丁会与上游此后的每次演进对抗；描述符现在恰好承载该钩子曾安装的路由状态。

**冷恢复时从团队记录而非描述符重新推导成员路由。** 拒绝：这会让团队记录与耐久描述符静默分歧；描述符是运行时已经遵循的唯一组合事实。

## 测试

适配完成后，fork 侧套件本地全绿（patent、self-evolve、better-sidebar、synapse、session 消费者）；`verify-tsconfig-paths`、翻译配对、暂存 lint 钩子通过。Linux lane 的 CI 是本次合并的平台级验证。
