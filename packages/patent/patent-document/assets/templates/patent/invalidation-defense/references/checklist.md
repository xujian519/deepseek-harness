# 无效宣告程序意见陈述书 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。本件为**被请求人（专利权人）侧的对外提交件**；内部评估（引用日志、结论分档、风险与应对预案）用 `invalidation-analysis` 模板，不要在本件里夹带内部记录。

## P0 — 必须通过

- [ ] 文书结构完整且顺序正确（`conventions.md §1` 的八个章节）
- [ ] 章节编号唯一、按序，与 `conventions.md §1` 的固定顺序一致
- [ ] 案件信息表填满（涉案专利号、专利名称、授权公告日、专利权人、无效宣告请求人、无效宣告请求日、转送文件通知书、指定答复期限届满日、陈述意见日期）
- [ ] 答辩意见概述写明答辩结论（请求维持有效 / 部分无效 / 在修改后的权利要求基础上维持有效）
- [ ] 程序性意见按 §2 的依据逐项核对：陈述意见的期限与不得延长（细则第 72 条、第 75 条）、审查范围、专利权人举证期限、一事不再理、听证原则；无异议时写明明确的否定结论
- [ ] 权利要求书的修改符合 §3：修改限于权利要求书、未扩大保护范围、未超出原说明书与权利要求书记载的范围；不在 §3 三种情形之一时不作删除以外的修改
- [ ] 未修改权利要求书时，说明段写明「未修改」，表 1 只登记一行且修改方式列写「未修改」
- [ ] 逐项答辩一节对应请求书实际主张的一项理由：无遗漏、无自行增加的理由；小节标题的法条与权项号与请求书一致
- [ ] 每节按「请求人的主张与证据 → 专利权人的意见 → 结论」三段组织；无结论式陈述（写「未公开」「无技术启示」都指出对方证据的具体位置与理由）
- [ ] 被主张的从属权利要求与其引用的权利要求同一法条路径，结论写明「在引用权利要求具备新颖性／创造性的基础上」
- [ ] `claim_chart_build`（mode=invalidity）的 `invalidity_conclusion` 与本件主张一致
- [ ] 请求人的每一份证据都有质证意见，真实性、合法性、关联性三项齐备（`conventions.md §5`）
- [ ] 证据清单逐条登记完整：专利文献写公开号与公开日，出版物写 ISBN、出版信息与所引页码，无标识可写的在标识列写「—」；全件编号一致（`conventions.md §6`）
- [ ] 证据编号两侧对齐（本件登记的是反证编号）：正文引用的反证编号全部登记在表 2，表 2 登记的反证编号全部在正文引用过，编号列无空行（渲染器的证据编号核对零告警）
- [ ] 未提交证据时按 §6 登记「未提交证据」一行，正文不引用它
- [ ] 逐权利要求结论表覆盖请求人主张的全部权利要求，「对应理由」列与第五章节的小节号对应
- [ ] 法条引用精确到条款号；审查指南引用精确到节号
- [ ] 无编造公开号、日期、段号
- [ ] 免责声明与密级完整，品牌变量已注入
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）
- [ ] 正文无内部工作记录（核验记录／待办／缺口披露／胜率分档／修订记录／内部任务编号），见 `conventions.md §9` 与 `invalidation-opinion/references/conventions.md` §6.1

## P1 — 应当通过

- [ ] 程序性意见与实体答辩不混写：程序异议单独成节，不掺入第五章节
- [ ] 质证意见只就证据本身陈述，实体结论写入第五章节并引用同一编号
- [ ] 引用反证支持己方主张时给出 pin-cite（书名、版次、页码）
- [ ] 答辩要点之间不重复、不矛盾
- [ ] 表格数字列使用 tabular 数字

- [ ] 导出 PDF 后抽查表格是否跨页断裂
- [ ] 出件核对：载体系 100902，陈述意见写 ⑥栏、附件列 ⑦栏，⑥栏填写不下时用 100014 附页续写，一式两份（`conventions.md §10`）
