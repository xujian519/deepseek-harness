# 命名规范

## 参数

- 英文大写短名：`L`、`W`、`T`、`D`、`HOLE_D`、`N_HOLES_X`。
- 数量类参数以 `N_` 开头，整型；尺寸类参数为浮点，单位毫米。
- 显示名（中文）写在构建器的 `LABELS` 常量里，不进参数表。

## 零件族与变体

- 零件族名即 `parts/<name>.py` 的模块名，小写，`[a-z0-9_]`。
- 变体名用于目录与文件名，不允许路径分隔符，建议 `尺寸-规格` 形式，如 `100x60`、`DN50-PN16`。
- 输出目录固定 `out/<part>/<variant>/`。

## 对象与文件

- 文档对象名英文：`Model`、`Params`、`Sheet`。
- 导出文件名固定 `model.step`、`model.stl`、`model.dxf`、`model.pdf`。
- 清单固定 `manifest.json`，位于变体目录根部。

## 图号

- 工程图图号由参数表外的外部编号传入，不写入零件族。
- 专利附图图号按申请文件顺序编号，不写入图形内部；两幅以上时写在图形正下方。
