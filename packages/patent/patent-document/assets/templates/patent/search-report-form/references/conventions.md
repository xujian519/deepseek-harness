# 表格式专利检索报告 — 版式惯例（Conventions）

> 生成或修改本模板前必读。与 `checklist.md`、`citation-log.md` 配套。

## 1. 分区顺序（固定）

1. 抬头（所名 + 密级）
2. 标题与副标题
3. 著录项（报告编号 / 检索日期 / 检索截止日 / 申请号 / 申请日 / 名称 / 类型 / 专利权人 / 委托方 / 检索人 / 审核人）
4. A. 主题的分类（IPC / CPC）
5. B. 检索领域
6. C. 在检索时查阅的电子数据库
7. D. 相关文件（按相关度降序）
8. 图例（`*` 引用文件的专用类型）
9. E. 检索结论
10. E.1 相关度分布
11. 附. 检索式执行记录
12. F. 检索范围与局限
13. 落款（检索人 / 审核人 / 日期）
14. 声明（固定内容，不可删除）

## 2. 值位与表格

- 值位一律用 `.fill`；横线长度随填写内容伸缩，空位保留最小长度。
- D 表行数 = 相关文件条数，附页表行数 = 检索轮次数；列宽随内容伸缩（`table-layout: auto`）。
- 超出本页时勾选「相关文件，参见附页」，附页复制本页与页眉。

## 3. 版式来源与视觉纪律

- A–E 分区对齐国家知识产权局《表格 220701（2011.4 版）》的检索记录部分。
- 本模板复刻官方检索记录版式，**刻意使用黑白表格线、不套用 `tokens.css` 品牌色**，以贴近官方原件外观；这是刻意选择，不是遗漏。
- 版式参数：正文 10.5pt、行距 1.5、版心 177mm。

## 4. 声明（固定）

文末声明段落是固定内容，不得删除或改写：本报告为检索分析文件，不是国家知识产权局作出的专利权评价报告。

## 5. 检索式记录规范

- 每轮记录：轮次、数据库、完整检索式、命中数、执行日期。
- 检索式保留原始布尔逻辑（字段与运算符）；命中数写阿拉伯数字。

## 6. 引用与溯源

同 `citation-log.md`；D 表即引证来源，正文每处对比引用对应 D 表一行。
