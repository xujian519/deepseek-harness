# 表格式专利检索报告 — 自查清单（Checklist）

> 输出 `<artifact>` / 定稿前逐项勾选。P0 必须全部通过。

## P0 — 必须通过

- [ ] 分区顺序与 `conventions.md §1` 一致
- [ ] 著录项填满（报告编号、检索日期、检索截止日、申请号、申请日、名称、类型、专利权人、委托方）
- [ ] A–E 分区完整；D 表每条相关文件六列填全
- [ ] D 表行数与正文「筛选出 N 篇相关文件」一致
- [ ] E.1 相关度分布的各类型篇数与 D 表一致，合计等于总篇数
- [ ] 检索式执行记录含数据库、完整检索式、命中数、执行日期
- [ ] 检索结论与相关度分布一致
- [ ] 声明段落完整，未被删除或改写
- [ ] 对外件不含内部工作章节（待办／待核／核验记录／修订记录等）
- [ ] 示例与产出件不得含真实案卷信息（专利号、名称、当事人、对比文件号均为虚构或已脱敏）
- [ ] 无占位文案泄漏给用户（`________` 类占位全部替换）

## P1 — 应当通过

- [ ] 关键词/分类号覆盖技术方案的多个独立技术点
- [ ] 检索式体现布尔逻辑与字段限制
- [ ] 表格数字列使用 tabular 数字
- [ ] 引用日志与正文断言一致

## P2 — 锦上添花

- [ ] 同时产出 `.md` 源稿与 `.pdf`
- [ ] 导出 PDF 后抽查跨页表格是否断裂
