# 侵权比对意见书 — 引用与来源规范

> 侵权比对意见书引用涉案专利、被控技术资料与现有技术；每条结论须可定位、可复核。

## 来源类型

| 来源类型 | 用途 | 徽标 |
|---|---|---|
| 授权文本 | 权利要求书、说明书、审查历史（禁反言证据） | `badge-evidence` 证据支撑 |
| 公开信息 | 被控产品宣传/拆解/说明书 | `badge-evidence` 证据支撑 |
| 客户提供 | 被控产品内部资料、委托方主张 | `badge-client` 客户提供 |
| 模型推断 | 特征分解建议、等同性论证 | `badge-model` 模型推断 |
| 假设 | 待取得的样品或数据 | `badge-assumption` 假设 |

## 规则

- 权利要求引用给出专利号与权利要求编号；引用文字与授权文本逐字一致。
- 被控物特征描述给出信息来源（URL、文件路径、页码）。
- 禁反言事项引用审查历史（OA 答复、说明书修改记录）。
- 公开日早于申请日的现有技术用作抗辩时，给出公开日与出处。
